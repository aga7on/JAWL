# Переносимая сборка JAWL Coding

Эта сборка содержит исходный код форка `codex/coding-agent`, документацию,
тесты, примеры конфигурации и списки зависимостей. Готовое виртуальное окружение
в архив не входит.

## Быстрый запуск на Windows

1. Распакуйте архив в каталог без системных ограничений на запись.
2. Установите Python 3.11 x64, если его ещё нет.
3. Запустите `start.bat` двойным кликом.
4. Дождитесь создания `venv` и установки пакетов из `requirements.txt`.
5. Пройдите настройку в интерактивном меню JAWL.

Первый запуск требует интернет-соединение и занимает заметно больше времени:
будут загружены Python-пакеты, а при первом использовании vector DB — локальная
embedding-модель.

То же самое из PowerShell:

```powershell
cd C:\path\to\JAWL-Coding
py -3.11 jawl.py
```

`jawl.py` сам создаст каталог `venv`, установит зависимости с учётом
`constraints.txt` и затем откроет меню.

## Что намеренно не включено

- `venv` и установленные Python-пакеты;
- `.git` и история репозитория;
- `.env` с API-ключами и токенами;
- рабочие `settings.yaml` и `interfaces.yaml`;
- Telethon session и другие данные авторизации;
- SQL, vector и graph базы памяти;
- локальные embedding-модели;
- sandbox, логи, pytest/cache и benchmark-артефакты;
- отдельный проект QWB и его Qwen-токены.

Отсутствующие локальные каталоги JAWL создаст автоматически. Конфигурация
формируется из файлов `config/*.example.yaml`; ключи вводятся локально и не
попадают в переносимый архив.

## Подключение к QWB

QWB является отдельным сервисом и в этот ZIP не входит. Если мост уже запущен на
том же компьютере, укажите в `.env` его OpenAI-compatible endpoint и локальный
ключ. Для другой машины сначала отдельно перенесите или установите QWB и получите
Qwen-токены через CDP.

Edge не требуется держать открытым для обычных direct-запросов после получения
токенов. Он понадобится при добавлении профиля или обновлении авторизации.

## Git после распаковки

ZIP предназначен для запуска и не содержит `.git`. Если форк должен сам работать
над собственной кодовой базой с полным Git-контуром, инициализируйте новый
репозиторий после распаковки:

```powershell
git init
git add .
git commit -m "Import JAWL Coding portable build"
```

Полная история разработки остаётся в исходном каталоге
`G:\AI\JAWL-Coding`, ветка `codex/coding-agent`.

## Проверка содержимого

Рядом с ZIP создаётся файл `.sha256`. Проверить архив можно командой:

```powershell
Get-FileHash .\JAWL-Coding-portable-2026-07-22.zip -Algorithm SHA256
```

Подробный технический отчёт находится в `CODING_AGENT_FORK_REPORT_RU.md`.
